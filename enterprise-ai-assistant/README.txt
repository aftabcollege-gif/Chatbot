دستیار هوشمند سازمانی — نسخه ۱.۰.۰
=====================================

یک دستیار مبتنی بر هوش مصنوعی کاملاً آفلاین برای ویندوز ۱۰ (۶۴ بیت) به بالا.
تمام پردازش‌ها (مدل زبانی، Embedding، RAG و OCR) روی همین دستگاه اجرا می‌شوند و
هیچ داده‌ای به بیرون ارسال نمی‌شود.

نیازمندی‌های سیستم
------------------
  - ویندوز ۱۰ نسخه ۶۴ بیت یا بالاتر
  - حداقل ۸ گیگابایت رم (پیشنهادی ۱۶ گیگابایت)
  - حدود ۱۵ تا ۲۵ گیگابایت فضای دیسک (شامل مدل‌ها)
  - پردازنده ۸ هسته‌ای یا بهتر
  - کارت گرافیک NVIDIA با CUDA (اختیاری، برای تسریع)

نصب
---
  ۱. فایل setup.exe را با دسترسی مدیر (Run as administrator) اجرا کنید.
  ۲. پیش‌نیازها (Visual C++ Redistributable و WebView2) به‌صورت خودکار نصب می‌شوند.
  ۳. پس از پایان نصب، برنامه از منوی استارت یا آیکون دسکتاپ اجرا شود.
  ۴. در اولین اجرا، «راه‌انداز اولیه» باز می‌شود: حساب مدیر و اطلاعات سازمان را وارد کنید.
  ۵. با همان حساب وارد شوید.

استفاده
-------
  - «گفتگو»: پرسش‌های فارسی یا انگلیسی بپرسید؛ پاسخ به‌همراه شماره منبع نمایش داده می‌شود.
  - «منابع»: فایل‌های PDF، Word، Excel، PowerPoint و متنی را بارگذاری کنید.
    پردازش (استخراج متن، تقطیع، ایندکس برداری) به‌صورت خودکار و آفلاین انجام می‌شود.
  - «دانش سازمانی»: تجربیات و درس‌آموخته‌ها را ثبت و منتشر کنید تا در جستجو و گفتگو بیایند.
  - «جستجو»: جستجوی ترکیبی (برداری + متنی) در تمام اسناد و دانش.
  - «پنل مدیریت»: مدیریت کاربران، نقش‌ها، دسترسی‌ها، لاگ‌ها، مدل‌ها و تنظیمات.

معماری
------
  - پوسته دسکتاپ: Tauri 2 + WebView2
  - رابط: React 18 + TypeScript + Vite + Tailwind (RTTL، فارسی، تم تاریک/روشن)
  - بک‌اند: Python FastAPI (بسته‌بندی‌شده با PyInstaller)
  - پایگاه داده: SQLite (FTS5 + افزونه sqlite-vec برای جستجوی برداری)
  - مدل زبانی: llama.cpp + Qwen2.5 (GGUF) با حالت جایگزین استخراجی آفلاین
  - Embedding/Reranker: ONNX Runtime (BGE-M3 / bge-reranker) با جایگزین قطعیِ بی‌نیاز از مدل
  - OCR: Tesseract (فارسی + انگلیسی) — در صورت نصب

خروج
----
  با بستن پنجره، برنامه در System Tray کوچک می‌شود. برای خروج کامل، از منوی راست‌کلیک
  آیکون سینی «خروج کامل» را انتخاب کنید.

پوشه داده کاربر
----------------
  %APPDATA%\EnterpriseAI\
    data\        پایگاه داده
    storage\     فایل‌های بارگذاری‌شده و آواتارها
    logs\        لاگ‌ها
    backups\     نسخه پشتیبان

ساخت از روی کد (برای توسعه‌دهندگان)
-----------------------------------
  پیش‌نیاز: Python 3.11، Node.js 20+، Rust، Inno Setup 6
  ۱. scripts\download-models.ps1       (دانلود مدل‌ها و باینری‌ها)
  ۲. scripts\download-prerequisites.ps1
  ۳. scripts\build.ps1                (خروجی: dist\Enterprise-AI-Assistant-Setup.zip)

در حالت توسعه، بک‌اند روی http://127.0.0.1:8741 و فرانت با `npm run dev` اجرا می‌شود.

پشتیبانی
--------
  برای گزارش مشکل، لاگ‌های پوشه %APPDATA%\EnterpriseAI\logs را ضمیمه کنید.
